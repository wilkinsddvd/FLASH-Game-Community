## 4. 本次发现的问题 / 优化项

1. **`/squad-assets/` 没有长缓存**：nginx 只给 `/assets/` 配了 30 天缓存；高程 `.bin`、等高线 `.svg`、地图/载具图片会重复下载。
2. **高程 `.bin` 未压缩**：488 KB/图，建议 nginx 开启 gzip/brotli 或预压缩。
3. **主包偏大**：Element Plus 全量在主包；建议拆分 vendor / 按需引入。
4. **Invasion 有 5 个数据层被跳过**（原始点位名对不上）：BlackCoast v3、Fallujah v3_CL、Gorodok v3/v4_CL、Harju v4_CL。
5. **图片缺 1 张**：MEI AGS-17 技术皮卡（当前显示类别图标）。

## 5. 结论

- 功能：15 条 Selenium + 10 条 API 全过，关键路径可用。
- 性能：本地 50 并发 API 0 失败、p95 46ms；静态 20 并发 p95 10ms；体积门禁通过。
- 下一步：补 nginx 缓存/gzip；可选继续做 100/200 并发与 30 分钟长稳（需 staging/独立服务器）。
