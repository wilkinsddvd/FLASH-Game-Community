## 修复：个人空间页"用户不存在" + 页面卡死
- 根因：提交 3133e69（8/28 勋章系统改造）误删了 SpacePage.vue 的 `const profile = ref(null)` 和 `const posts = ref([])` 两行声明，只剩 badges。
- 后果：`profile.value = ...` 抛 ReferenceError → 被 catch 吞掉 → 误报"用户不存在"，页面永远卡骨架屏。
- 修复：恢复两行声明（commit ab30975）。
- 教训：改动 .vue 时别误删 ref 声明；这类"报错文案误导"问题先查变量是否已声明。
