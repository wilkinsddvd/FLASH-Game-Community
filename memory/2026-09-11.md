## 排查（续）：小程序「编制查询未正常显示」→ 静态资源域弄错

- 现象：编制页能进，但阵营旗帜/载具图标不显示。
- 根因：`/squad-assets/*`（旗帜 PNG、载具图）是**前端 public 资源，后端 API 不提供**（后端只 mount 了 `/uploads`）。小程序把相对路径拼到 API 域 `http://127.0.0.1:8000` 上 → **全部 404**；实测 `:3000` 下均 200。

- 修法（已做）：`miniprogram/config/index.ts` 拆成两个根地址：
  - `API_BASE`（默认 `:8000`）用于接口 + `/uploads/*`；`STATIC_BASE`（默认 `:3000` = 前端 dev server）用于 `/squad-assets/*` 等前端资源；都支持 `flash_api_base`/`flash_static_base` 本地覆盖。
  - 新增 `imageUrl()`：遇到 `data:image/svg` 返回空串，让页面走“代号文字”兜底（WXML 里 `<image wx:if>` + `<text wx:else>` 已备好）。

- **教训：任何相对资源路径都要先确认是哪个服务提供的，不能一律拼在 API 域上；上线时 `STATIC_BASE` 的域名要加入 mp 后台的 downloadFile 合法域名。**
