## wechat-monitor 项目（Mac 微信防撤回/消息监控）

用户需求：Mac 上实现微信防撤回 → 纯 Python 监控微信消息并保存。

### 完成的事
- 新建项目 `~/Desktop/dev/wechat-monitor/`（2026-08-10 起从 FLASH 仓库独立，git 已推送）
- 定位微信 4.1.11 新数据目录：`~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/<wxid>/db_storage/message/message_0.db`
  （旧版 `Application Support/.../Message/msg_*.db` 路径已废弃）
- 数据库为 SQLCipher 4 加密（AES-256-CBC + HMAC-SHA512, reserve=80, page_size=4096, 每库独立 salt+key）
- 发现 `all_users/login/<wxid>/key_info.db` 有 `LoginKeyInfoTable`，但 key_info_data 是加密 blob，固定32字节 `6EB001AA...4FE9` 不是直接密钥，AES 猜测失败
- 用户已执行去签名：`sudo codesign --force --deep --sign - /Applications/WeChat.app`（去掉 Hardened Runtime，微信升级后需重做，resign_wechat.sh 已备好）

### 关键结论（踩坑记录）
- 微信 4.1.10+ 内存中**不再有** `x'<64hex key><32hex salt>'` 字符串缓存（内存扫描 0/33 失败）
- `sqlite3_key` 符号已被剥离，老式 lldb 断点方案失效
- 唯一可行路径：**hook CommonCrypto `CCCrypt`/`CCCryptorCreateWithMode`** 截获 32 字节 AES key（arm64 寄存器: CCCrypt key=x3 len=x4；CreateWithMode key=x5 len=x6）
- 参考项目: Evanyuan-builder/wechat-4.1.10-macos-key（GitHub API 可访问，raw.githubusercontent 超时）
- DMCA 提示：ycccccccy/wx_key 因腾讯法务下架，这个方向敏感，注意低调

### 项目文件
- `wx_monitor.py` — 主监控（轮询 message_*.db，自动读 keys.json，去重写入 wechat_monitor.db）
- `extract_key.py` — 内存扫描版（4.1.11 已失效，备用；日志 tee 到 extract.log）
- `keyhunt.py` + `hunt.sh` — lldb 拦截 CCCrypt（新方案，待测试）
- `verify_keys.py` — 验证 hunted_keys.txt → 生成 keys.json
- `resign_wechat.sh` — 去签名脚本
- venv 依赖：sqlcipher3 + pycryptodome
