# Banner 保存问题修复 + 首页左右侧布局（2026-10-19）

## 1. 问题结论：后端能存，前端在“图片为空”时静默失败

复现与排查结果：

| 检查项 | 结果 |
|---|---|
| `GET /api/admin/banners` | 200 |
| `POST /api/admin/banners`（带合法 `image_url`） | 201，数据入库 |
| `PUT /api/admin/banners/{id}`（整行回传 / 只传 status） | 200 |
| `DELETE /api/admin/banners/{id}` | 204 |
| `image_url = ""` 或缺失 | **422**：`string_too_short` / `missing` |

根因有两条：

1. **后台表单只有“图片URL”文本框，没有上传入口**。没填图片地址就点保存 → 后端 422；但 `save()` 没有 `try/catch`，`apiRequest` 又把 FastAPI 的 422 `detail` 数组直接塞进 `new Error()`，提示不可读，表现为“点保存没反应 / 保存不了”。
2. **表单没有 `status` 字段**，无法设置显示/隐藏；列表里的状态只能看不能改。

顺带发现：Banner 管理接口只校验了“已登录”，任何登录用户都能增删改 Banner。已一并改为 `require_admin`。

## 2. 已做的修改

### 后端 `FLASH_END_PRO`

- `api/cms.py`
  - 新增 `POST /api/admin/banners/upload`：JPG/PNG/WebP/GIF，≤5MB，落到 `uploads/banners/`，返回 `{ url }`
  - Banner 后台列表/新增/修改/删除全部改为 `Depends(require_admin)`
- `schemas/cms.py`
  - `BannerCreate` 新增 `status`（默认 1，0/1）

### 前端 `frontend/src`

- `pages/admin/BannerManage.vue`（重写）
  - 新增加传图片按钮 + 预览 + 4:5 预览框
  - 标题、图片必填校验；保存前拦截并给中文提示
  - 保存 / 删除 / 状态切换全部 `try/catch` + `ElMessage`
  - 列表新增预览列、显示开关（可直接隐藏/显示）
  - 新建/编辑表单新增 `status` 开关
- `api.js`
  - 422 的 `detail` 数组格式化为可读文本（`字段: 原因`）
  - `FormData` 请求不再手写 `Content-Type`（浏览器自己带 boundary）
  - 新增 `uploadFile(path, file)` 辅助函数
- `components/SideBanners.vue`（新增）
  - 左右两条 sticky 侧栏；Banner 按顺序交替分栏（1/3/5 左，2/4/6 右）
  - 4:5 卡片、图片 cover、底部标题渐变遮罩
- `pages/HomePage.vue`
  - 移除顶部 `el-carousel`
  - 改为三列 grid：左栏 / 内容 / 右栏
  - ≤1240px 隐藏侧栏，改为顶部横向滑动 Banner 条
- `router.js` / `App.vue` / `style.css`
  - 首页路由 `meta.wide`，内容容器放宽到 1560px，给左右侧栏留空间

## 4. 使用说明

- 后台 → Banner管理 → 新建Banner → 上传图片（建议竖图 4:5）→ 填标题/跳转/排序/显示 → 保存
- 首页桌面端：左/右交替展示；窄屏：顶部横向滑动条
- 想调整左右顺序：改「排序」即可，数字小的先出现（第 1 条在左，第 2 条在右，依此类推）
