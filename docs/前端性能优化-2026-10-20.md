# 前端性能优化（nginx 缓存/压缩 + 按需引入）· 2026-10-20

> 背景：`tests/reports/SUMMARY-2026-10-20.md` §4 列出的 3 个优化项（`/squad-assets/` 无长缓存、高程 `.bin` 未压缩、主包偏大）本轮全部处理完。
> 提交：`67d719f`（已 push origin/master）。**本地已验证，尚未部署到服务器。**

## 1. 结论（已实现）

| 指标 | 优化前 | 优化后 | 变化 |
|---|---:|---:|---:|
| 首屏 JS（gzip，体积门禁口径） | 356.0 KB | **99.3 KB** | −72% |
| 主入口 `index-*.js`（gzip） | 364.1 KB | **68.1 KB** | −81% |
| 首屏 CSS（gzip） | 49.7 KB | 49.7 KB | 不变（见 §4） |
| 高程 `.bin` 单图传输 | 500,000 B | **191,258 B** | −62% |
| 等高线 `.svg` 单图传输（albasrah） | ≈192 KB | **58.3 KB** | −70% |
| `/squad-assets/` 缓存 | 无 Cache-Control | 图片 30d / 数据 7d | ✅ |

## 2. nginx（`frontend/nginx.conf` + `nginx.test.conf`）

- **gzip**：`gzip on` + `gzip_types` 覆盖 `application/octet-stream`。高程 `.bin` 走 octet-stream，之前完全没压缩，现在 500KB → 187KB。
- **`/assets/`**：维持 30d immutable（vite hash 产物）。
- **`/squad-assets/`**：
  - 图片/字体（webp/png/jpg/svg/woff2）→ 30d
  - 数据文件（bin/json/js/css）→ 7d（数据会随版本重生成，别锁死）
  - 统一 `try_files $uri =404`：**缺文件直接 404**，不再 fallback 成 `index.html`（否则前端 fetch `.bin` 会拿到 HTML 解析出垃圾高程）
- **`/index.html`**：`no-cache`，保证发版即生效，不会因为 SPA fallback 命中缓存拿到旧入口。

实测（nginx:alpine + 本地 dist，8088 端口）：

```
/                          → Cache-Control: no-cache
/assets/xxx.js             → gzip + immutable 30d
/squad-assets/heightmaps/x.bin → gzip + public 7d + application/octet-stream
/squad-assets/contours/x.svg   → gzip + public 30d
/squad-assets/heightmaps/nope.bin → 404（不是 200 HTML）
```

## 3. 按需引入（`vite.config.js` + `src/main.js`）

- 新增 `unplugin-vue-components` + `ElementPlusResolver({ importStyle: false })`：
  模板里的 `<el-xxx>`（833 处、40+ 组件）由插件按需 import，**删掉 `app.use(ElementPlus)`**。
- **图标不再全量注册**：原来 `import * as ElementPlusIconsVue` + 循环注册整套图标，实际只有 `AdminRegisterPage` 用到一个 `Lock`（本来就已经单独 import）→ 整段删除，单项回收 ~38KB gzip。
- `v-loading` 指令无法被组件解析器处理 → 显式 `app.use(ElLoading)` 注册（7 处使用）。
- `importStyle: false`：样式继续用 `element-plus/dist/index.css` 全量引入，**故意不逐组件引样式**，避免漏掉 `ElMessage` / `ElMessageBox` / `ElLoading` 这类服务式组件（它们不走模板解析器，漏了就是白屏/无样式）。CSS 50KB gzip 且可长缓存，性价比不如 JS。

## 4. 还可以做但本轮没做（有意留）

1. **CSS 按需**：改 `importStyle: 'css'`，再手动补 `el-message.css` / `el-message-box.css` / `el-loading.css` / `el-overlay.css`，预计 49.7 → ~25KB gzip。收益小、漏引风险靠截图才能发现，暂不动。
2. **`vendor` 手动分包**（`manualChunks`）：只改善跨版本缓存命中，不减少首屏字节。
3. **brotli**：`nginx:alpine` 不带 brotli 模块，要换镜像自己编，暂不做。
