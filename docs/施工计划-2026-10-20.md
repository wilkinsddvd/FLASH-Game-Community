### R5 · 点位推测：RAAS + Invasion（1.5–2 天）

**路由**

```
/squad/points                    模式选择
/squad/points/:mode              该模式地图列表
/squad/points/:mode/:layer       点位工具
```

- mode：`raas | invasion`（只做这两个，其他模式不出现）
- 旧链接：`/squad/raas` → `/squad/points`；`/squad/raas/:layer` → `/squad/points/raas/:layer`

**数据**

- 重构 `scripts/build-raas-data.py` → `scripts/build-points-data.py`
- 产出：
  - `data/squad/points-meta.js`（模式 + 地图/图层索引，很小）
  - `data/squad/points/raas.js`
  - `data/squad/points/invasion.js`
- 两种模式统一图层结构：

```js
{
  mode, raw, name, map, ver, community, size, corners, teams,
  lanes, laneLinks, nodes,      // RAAS 原生 lane / Invasion 由 links 转换而来
}
```

- Invasion 解析方式（数据已核验，44 层 / 22 图）：
  - `capturePoints.clusters.links` 本身就是「进攻方主基地 → 5 个进攻点 → 防守方主基地」的多条链
  - `capturePoints.clusters.pointsOrder` 会重复出现进攻方主基地，按它切分即可得到 A/B/C/D/E 各条进攻 lane
  - 每层 1–5 条 lane（20 层多 lane，24 层单 lane）；每条 lane 固定 5 个进攻点
  - 转成与 RAAS 相同的 `lanes / laneLinks / nodes` 结构，**直接复用 `buildRoutes` + `solveRoutes`**
  - `bidirectional: false`：Invasion 进攻方出生点固定为 team1 主基地，不需要像 RAAS 那样选边
- 图层页动态 `import()` 对应模式文件；地图列表只读 meta
- `raas-data.js` 保留 re-export 过渡

**页面**

- 模式卡只有 2 个：
  - **RAAS**：随机 lane，选出生点后逐步推测
  - **Invasion**：进攻方路线推测，进攻方出生点自动选中
- 地图列表只显示该模式有图层的地图
- Invasion 图层页复用 RAAS 的地图、确认面板、路线状态
- Invasion 交互：
  - 进攻方主基地自动作为第 0 点（不需要选边）
  - 地图上只展示进攻候选点，不展示防守方点位
  - 每确认一个实际看到的点，路线数收窄，显示「X / Y 条进攻路线仍然成立」
  - 单 lane 图层不直接剧透整条路线，仍按「确认—收窄」的方式展示；顶部提示「本图层仅 1 条候选路线」
- 防守方主基地只作为终点标记，不作为需要确认的点位

**验收**

- `/squad/points` 不加载任何 `points/*.js`
- RAAS 39 图层全部可开，`test-raas-solver.mjs` 全过
- Invasion 44 图层全部可开；抽样 10 层，每条 lane 的 5 个进攻点与原始 `pointsOrder` 一致
- 多 lane 图层：确认 1–2 个点后路线数正确收窄；单 lane 图层：路线数始终为 1，不出现「不存在」
- 其他模式（AAS/Seed/Skirmish/TC/Insurgency/Destruction）**不出现在页面与数据包中**
- 旧链接自动跳转

### R6 · 火控计算器（3 天）

**路由 / 导航**

- `/squad/fire-control`，导航「火控计算器」

**首批武器**

| 武器 | 初速 | 单位 | 射界 |
|---|---|---|---|
| 标准迫击炮 | 110 | 密位 | 800–1579 |
| 技术车迫击炮 | 110 | 度 | -45–135 |
| M1064 M121 | 142 | 度 | -45–85.3 |
| Hell Cannon | 95 | 度 | 10–85 |
| UB-32 | 表 | 度 | -25–35 |
| BM-21 | 200 | 度 | -45–135 |

**计算**

- `d = hypot(dx, dy) / 100`
- `h = z_target - (z_src + heightOffset)`
- `g = 9.78 × gravityScale`
- `inner = v⁴ - g(g d² + 2 h v²)`
- `θ_low/high = atan((v² ∓/± √inner) / (g d))`
- `TOF = (v sinθ + √(v² sin²θ - 2gh)) / g`
- `mil = deg × 6400 / 360`
- 校验射界、最小射距、飞行时间

**基准（标准迫击炮，h=0）**

| 距离 | 密位 | 飞行时间 |
|---:|---:|---:|
| 300 m | 1475 | 22.3 s |
| 600 m | 1342 | 21.8 s |
| 900 m | 1185 | 20.7 s |
| 1200 m | 925 | 17.7 s |

**交互**

- 选武器 → 选地图 → 点炮位 → 点目标
- 输出：距离、方位角、仰角（主/备分支）、飞行时间、最大射程、超程/近界提示
- 支持交换炮位/目标、清空、复制结果、多目标表
- P1 高度差手输（默认 0）；P2 自托管降采样高程（128×128，30–60KB/图）

**代码**

- `pages/FireControlPage.vue`
- `components/FireControlMap.vue`
- `utils/fire-control.js`
- `data/squad/weapons.js`
- `scripts/test-fire-control.mjs`

**验收**

- 4 组基准 ±1 mil / ±0.1 s
- 超程不显示假角度
- 交换两点方位角翻转 180°
- 390px 宽无横向滚动
