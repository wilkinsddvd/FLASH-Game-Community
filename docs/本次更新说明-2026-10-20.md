### R6 火控计算器
- 路由 `/squad/fire-control`，导航「火控计算器」
- 流程：选地图 → 点炮位/目标（或输入游戏网格坐标）→ 出密位/角度
- **网格坐标**：
  - 大格 300m × 300m，从地图左上角起算；列 A/B/C…，行 1/2/3…
  - keypad / sub-keypad 均按小键盘布局
  - 支持 `D4` / `D4-6` / `D4-6-3`（也兼容空格、斜杠分隔）
  - 地图点击自动回填三级坐标；鼠标移动显示当前网格
- **自动高程**：
  - 23 张地图 × 500×500 高程，量化 0.1m int16，`.bin` 约 488KB/图
  - 双线性采样，行 0 = 北
  - 自动算炮位/目标海拔与高差；可切手动高差
  - 缺失时回退 `h=0` 并提示
- **等高线图**：
  - 每张地图生成 SVG，放在火控地图下方
  - 等高距自适应：<10m 用 1m，<50m 用 5m，<200m 用 10m，<500m 用 20m，>500m 用 50m
  - 每 5 条加粗并标注高程
  - 主图可一键叠加等高线
- 武器：标准迫击炮 / 技术车迫击炮 / M1064 M121 / Hell Cannon / UB-32 / BM-21
- 弹道基准自检：300m→1475mil、600m→1342mil、900m→1185mil、1200m→925mil，全部通过
