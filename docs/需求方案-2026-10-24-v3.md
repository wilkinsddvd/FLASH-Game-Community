## 4. 需求三：英文版（口径已改）

### 4-A 三层结构

```
界面文案  locales/{zh-CN,en-US}/*.js   ← vue-i18n@11，约 1200 key，懒加载
数据词典  data/squad/i18n-names.js      ← 新增，约 339 条，展示层映射
原始数据  squad_config / factions.js    ← 只存中文，不动
```

`i18n-names.js` 结构（键全部用稳定 ID，不用中文名）：

```js
FACTION_EN   { RGF: 'Russian Ground Forces', TLF: 'Turkish Land Forces', … }        // 17
ROSTER_EN    { 'rgf-motorized': '3rd Motorized Rifle Brigade', … }                  // 80
VEHICLE_EN   { '卡玛兹5320运输卡车': 'KamAZ-5320 Transport Truck', … }                // 203 canonicalKey
VEHICLE_TYPE_EN { '运输卡车': 'Transport Truck', … }                                 // 25
VEHICLE_CAT_EN  { logistics: 'Logistics', … }                                      // 7
ROSTER_TYPE_EN  { 摩托化: 'Motorized', … }                                          // 7
```

- **载具英文名来源**：`vehicle-specs.js` 的 `page` 字段（Squad 官方 Wiki 英文页名）已覆盖 **194/203** 个规范型号，自动生成 + 中文变体后缀映射（运输卡车→Transport Truck、补给卡车→Logistics Truck…）；剩 **9 个**人工补：LPPV 轻型巡逻车/遥控武器站、LUVW 运输车/C6机枪/运兵载具、轻型改装皮卡 AGS-17、M1117、OH-6A/OH-6 侦察型
- **编制英文名来源**：无官方英文数据（wiki 无编制页）→ 按军事译名规范人工译，产物落 `docs/vehicle-name-en-review.csv` / `docs/roster-name-en-review.csv` 供你抽查（你是玩家，扫一眼就知道哪个译名不对）
- 卡玛兹：按你的答复，英文名同样用 **KamAZ-5320**（不是 5350）

### 4-B 展示层改造点

| 位置 | 改动 |
|:-|:-|
| `vehicle-view.js` / `vehicle-stats.js` | 聚合仍按 `canonicalKey`（中文键）不变；输出 `displayName` 按当前语言取 |
| 载具信息页 / 详情 / 浮窗 / 编制页载具表 | 统一走 `vehicleLabel(v, lang)`，禁止直接渲染 `v.name` |
| 编制卡片、编制详情标题、面包屑、侧栏、导航 | 走 `rosterLabel(r, lang)` / `factionLabel(f, lang)` |
| 搜索 | 同时匹配中英文（任一命中即出），不受当前语言限制 |
| 排序 | `Intl.Collator(lang, {numeric:true})`，英文按字母、中文按拼音（现状 `localeCompare` 改显式传入 lang） |
| 语言切换 | 顶栏「中 / EN」胶囊；`localStorage.flash_lang`；同步 `<html lang>`；不刷新、不改路由 |
| 缺译兜底 | 显示中文 + `zh` 小标（不静默留空） |
| 后台 `/admin/*` | 保持中文 |

### 4-C 漏译门禁

`frontend/scripts/lint-i18n.mjs`（CI/构建前置）：

1. 载入当前语言数据（`/api/squad/public` 回落 `factions.js`）
2. 扫 17 阵营 / 80 编制 / 203 型号 / 25 类型 / 7 类别 / 7 编制类型，逐项查 EN 词典
3. 缺任一项 → 非 0 退出并打印清单；中文残留（英文值里出现 CJK 字符）同样报错
4. 白名单：卡玛兹等保留原型号数字的项、`vehicle-specs` 里刻意中文的备注

### 4-D CMS 文章双语（未变）

`model/article.py` 加 `title_en/summary_en/content_en` → `db/db.py` 幂等补列 → schema 增字段 → `/api/cms` 支持 `?lang=en`（缺则回退中文 + `has_en`）→ 后台「中文 / English」Tab → 前端跟随语言取、缺英文加 `zh` 标。范围外：Banner、系统通知、视频标题、答题库、留言板。
