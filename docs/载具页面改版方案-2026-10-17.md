## 1. 页面结构

### 1.1 单视图：按阵营

```
页头：SQUAD 载具信息
      17 阵营 · 80 编制 · 262 型号
[搜索框] [全部类别] [坦克] [步战] ... [阵营快捷筛选]
[标签筛选：反装甲 / 防空 / 两栖 / 空降 / 侦察 / 补给 / 运输 ...]

▼ USMC 美国海军陆战队        17 型号
   🛡️ 坦克
     [ 大图标卡片 ] [ 大图标卡片 ]
   🚜 步战车
     ...
▼ USA 美军陆军              28 型号
   ...
```

- 阵营顺序沿用现有 `FACTIONS` 顺序
- 阵营内按类别分组，类别顺序固定：坦克 → 步战 → 装甲运兵 → 侦察/突击 → 运输/补给 → 直升机 → 火炮
- 载具卡片：大图标显示区约 **120×90px**（宽屏可 140×105）
- 卡片上只显示：图标、名称、2～3 个标签
- 不再出现数量、台数、排序列

### 1.2 悬停浮层（桌面）

- 进入图标 **120ms** 后弹出；离开 150ms 关闭
- 浮层内容：
  - 大图约 **360×240**（512px 原图，`object-fit: contain`）
  - 名称 + 阵营 + 类别 + 类型
  - **标签行**
  - **武器列表**：武器名 / 口径 / 弹药数（如 `120mm M256 · 42 发（21 AP + 21 HEAT）`）
  - 票数、复活时间、初始延迟
  - 备注
- `Teleport` 到 body，按视口边缘翻转/夹紧，避免被容器裁切
- 同一张大图只加载一次，hover 时才预加载

### 1.3 移动端

- 无 hover → 点击卡片弹出底部抽屉
- 抽屉内容与桌面浮层一致；大图置顶
- 点击遮罩/关闭按钮退出；保留滚动位置

### 1.4 删除项

- 删除「🚗 按载具」按钮与整张表格
- 删除按载具排序、总台数、逐编制明细表
- `vehicle-stats.js` 中仅页面不再使用的聚合字段可保留，避免影响其他地方；页面只取阵营/类别/型号数

## 2. 标签系统（新增需求 5）

### 2.1 标签类型

每个载具（按「阵营 + 载具名」这一条）都至少带两类标签：

| 类型 | 例子 | 来源 |
|---|---|---|
| 阵营 | `USMC`、`PLA`、`RGF` | 所属阵营 |
| 类别 | `主战坦克`、`步兵战车`、`运输/补给` | `category` |
| 角色/特征 | `反装甲`、`防空`、`两栖`、`空降`、`侦察`、`补给`、`火力支援`、`高机动` | 类型 + 武器 + 编制用途 |
| 变体 | `USMC 型`、`M2 武器站`、`Mk19 武器站`、`M240 武器站` | 同名跨阵营/同阵营不同武器站 |
| 使用范围（弱展示） | `专属`（仅 1 个阵营）、`通用`（多阵营） | 统计结果 |

### 2.2 现有数据基础

- 262 个名称中：**195 个只出现在 1 个阵营**，49 个出现在 2 个阵营，9 个 3 个，9 个 4 个及以上
- 因此「按阵营打标签」不会造成大面积重复；共享载具（橡皮艇、四轮摩托、M1151 陶氏等）会在各阵营分别出现，并带各自阵营标签

### 2.3 展示规则

- 卡片上最多显示 **3 个 chip**：`阵营` + `类别` + `1 个角色标签`
- 浮层里显示完整标签（含变体、使用范围）
- 标签筛选：点角色标签可过滤（与类别/阵营筛选叠加）
- 标签去重、按优先级排序：阵营 → 类别 → 角色 → 变体

### 2.4 数据落点

新增 `frontend/src/data/squad/vehicle-tags.js`：

```js
{
  key: 'M1A1',            // 规范型号（仅用于合并 spec）
  name: 'M1A1',           // 原始名称，262 个名称都保留
  faction: 'USMC',
  tags: ['USMC', '主战坦克', '反装甲'],
  variant: 'USMC 型',
  roleTags: ['反装甲'],
  usage: '专属'
}
```

- 自动生成规则 + 手工覆盖表（`overrides`）结合
- **不删除任何名称**；同名异写（`M939运兵卡车` / `M939 运兵卡车`）也保留，变体标签标注

## 3. 武器 / 弹药数据

### 3.1 数据源

- Squad Wiki `Category:Vehicles`：**134 个车辆页面**（已实测）
- 通过 AllOrigins 代理访问 MediaWiki API（本机/服务器直连 fandom 被网络拦截）
- 每页取：
  - infobox `image`
  - Gameplay / General Information 段落里的武器、弹药、乘员、烟幕
  - 页面 revision 时间戳
- 交叉校验：Squad Wiki GitHub 武器数据管线（武器名/口径/弹匣），以及官方补丁说明

### 3.2 字段

```js
{
  key: 'M1A1',
  displayName: 'M1A1',
  class: '主战坦克',
  crew: 3,
  seats: 4,
  armaments: [
    { name: '120mm M256 滑膛炮', type: 'main_gun', ammo: 42, detail: '21 AP / 21 HEAT' },
    { name: 'M240C 同轴机枪', type: 'coax', ammo: 2000 },
    { name: '40mm 烟雾发射器', type: 'smoke', ammo: 2 }
  ],
  source: 'https://squad.fandom.com/wiki/M1A1',
  sourceRevision: '2026-xx-xx',
  gameVersion: '10.6.2'
}
```

- 262 个名称 → `aliases` 映射到约 150 个规范型号；**名称本身不合并、不删除**
- 同底盘不同武器站（M1151 M2/M240/Mk19）共用车身图，但 spec 的 `armaments` 分开
- 拿不到的数据写 `null` + `待核对`，不猜

### 3.3 质量校验

- 262 个名称 100% 有 spec 映射或明确 fallback
- 战斗载具至少 1 门武器；`ammo` 为正整数或 null
- 每个 spec 有 source + revision
- 标签至少包含「阵营 + 类别」；角色标签不能为空（无特征给 `通用`）
- 生成 `tmp_work/vehicle-specs-report.json` 供审核

## 4. 图片核对与替换

### 4.1 审计

- 262 个名称 → 现有 59 张图，生成四类审计表：正确 / 车族通用 / 错误 / 缺失
- 自动标红：同一图片跨多个车族、文件名与型号不符
- 先出审计报告，不直接替换

### 4.2 取图标准

- 来源：Squad Wiki 页面 infobox 原图
- 优先完整**车身侧面 / 前 3/4 视角**，不用炮塔特写、驾驶舱、剪影、图标
- 统一：最长边 512px、WebP、命名 `<阵营>_<型号>.webp`（同底盘可共用一张）
- 同型号跨阵营有外观差异时，允许 `faction` 覆盖图；没有就共用并在浮层标注

### 4.3 审核

- 生成「按阵营 contact sheet」：一页看完该阵营所有载具图 + 名称 + 标签
- 你逐张确认后，再替换 `public/squad-assets/vehicles` 与 `icon_url`
- 页面底部加致谢：
  > 载具图片与部分资料来源于 Squad Wiki（squad.fandom.com），采用 CC BY-SA 4.0 许可。
