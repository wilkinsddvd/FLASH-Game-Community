## 1. 标签体系（简化版）

### 1.1 每个载具最多两个标签

| 标签 | 规则 | 例子 |
|---|---|---|
| 阵营标签 | 必填，来自所属阵营 | `USMC`、`PLA`、`RGF` |
| 类别标签 | 仅当该型号能准确归入下面 7 类之一 | `坦克`、`轮式步战车` |

- 不再有 `反装甲 / 防空 / 两栖 / 空降 / 侦察 / 补给 / 火力支援` 等角色标签
- 不再有 `变体 / 专属 / 通用` 标签；同名跨阵营差异用名称 + 浮层文字说明，不加标签
- 卡片：最多 2 个 chip（阵营 + 类别）
- 浮层：阵营 + 类别；原始 `type`（如「主战坦克」「防空装甲车」）作为普通文字展示，不算标签

### 1.2 类别标签词表（7 个）

1. **补给载具**：运输卡、补给卡、弹药/物资运输、橡皮艇等后勤载具
2. **轮式步战车**：轮式底盘 + 步战车火力（如 LAV-6、ZBL08、BTR-82A 视型号确认）
3. **轮式装甲运兵车**：轮式装甲输送车（如 M1126、BTR-80、ZSL92）
4. **履带式步战车**：履带底盘步战车（如 BMP-2/3、M2A3、FV510、ZBD04A）
5. **突击炮**：直接火力支援/ assault gun（如 M1128 MGS、2S25 Sprut、ZLT05）
6. **坦克**：主战坦克（M1A1/A2、T-72/T-90、挑战者 2、豹 2）
7. **直升机**：运输/突击直升机

### 1.3 不属于这 7 类的载具

现有数据里还有一些类型无法准确归入：

- 侦察/突击/技术车辆：M1151、M-ATV、改装皮卡、BRDM-2、四轮摩托
- 火箭炮/迫击炮车：BM-21、M1064A3 M121
- 防空车：BTR-ZD
- 其他特殊载具

处理方式（推荐）：
- **只显示阵营标签**，不硬塞进 7 类
- 浮层里保留原始 `type` 文字
- 页面增加一个「未分类」筛选 chip，方便找到它们（这是筛选项，不是标签）

> 如果你希望这些也必须有类别标签，需要再增加词表（例如「侦察车」「火炮」「防空车」），但这会超过你限定的类别范围。

现有 `category` 粒度较粗且部分不准（例：M1128 被归到 `artillery`，M60T 用了 BMP-1 图）。因此不能直接按 `category` 批量套 7 类，必须按型号逐条确认。预计需要人工判断的规范型号约 150 个。
